# 视觉方向与 STYLE.md

风格是每个项目现场设计的，不从内置库里套。

## 出方向
1. 从题材、受众、场合、品牌约束出发，写 2–3 个**真正不同**的方向：至少在"画面媒介（扁平矢量 / 纸艺 / 3D 质感 / 档案实物 / 手绘 / 数据仪表 / 实拍素材 ...）、色彩逻辑、运动性格"中两项上拉开。只换配色不算不同方向。
2. 每个方向一段话：一句话描述、色板（4–6 色 HEX）、字体角色、运动性格、标志性手法 1–2 个、这个方向适合/不适合本片的理由。
3. 每个方向渲 1–3 张关键帧给用户挑（`render.py --stills`）。需要插画、背景、质感图时用 `imagegen.py`，图里不要放文字，文字由代码排。
4. 用户选定后，把选中的方向写成项目根目录 `STYLE.md`，之后所有镜头遵守它。

## STYLE.md 模板
```
# <方向名>
一句话：
## 不变量（每一镜都要满足）
- 媒介/材质：
- 色板：底色 / 主色 / 强调色 / 文字色（HEX）；强调色只用于……
- 字体：标题 / 正文 / 数字（字号范围）
- 运动：缓动、节奏、镜头语法（推/拉/横移/切的用法）
- 标志性手法：
## 禁止
- （品牌禁忌、不吉利元素、竞品色、与题材冲突的意象……）
## 字幕样式
```

## 内置风格卡
`references/mg-styles.md` 收了 15 种成熟动效风格（扁平矢量、线条、等轴、3D 质感、逐帧手绘沸腾、拼贴、液态、形变、包豪斯、复古、玻璃拟态、花字、贴纸科普、像素、HUD）的"认出它靠什么 / 怎么做 / 在本引擎里怎么落地"，以及纸张、颗粒、尘点、胶带纹理包。用户点名这些风格、或你需要一个成熟参照时读；只学规则，不照抄示例片的故事和文案。

## 外部风格库
用户点名或明确想要某种成熟风格（如赛博、浮世绘、档案灯台、新闻片），按 `external-skills.md` 取对应仓库的风格卡作为 STYLE.md 的起点；只学风格规则，不照抄其示例片的故事、镜头和文案。

## 品牌与禁忌
- 品牌色、Logo、标准名称、禁用词写进 `project.json.brand`（`terms` 旧→新、`banned`、`credit` 署名），lint 会扫描旁白、画面数据和代码。
- 按目标受众检查文化禁忌（颜色、数字、手势、字词寓意），拿不准就问用户。例：中文场景慎用大面积"黑/死/白事"意象做结尾或品牌符号。
