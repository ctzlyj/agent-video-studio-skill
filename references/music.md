# 配乐：代码动画用内置 BGM，AI 剧用 MiniMax Music

先看路线，再看配乐。**内置 BGM 只服务代码动画；AI 漫剧/真人短剧的主配乐必须是一个用户听过并确认的 `music.file`。**

| 路线 | 默认配乐 | 备注 |
|---|---|---|
| promo / explainer / motion-graphics / documentary / voiceover / script-first / hybrid | 内置 BGM `{"track":"default"}` | 代码动画默认，不用问用户；hybrid 按代码动画处理 |
| ai-comic-drama / ai-live-drama | **尚未选定**（`music: {}`） | 先按题材用灵境 MiniMax Music 生成 2 首候选，客观粗筛，用户试听选定后写 `music.file` |
| 任意路线，用户明确要自己的歌 | `music.file` | 须有授权；AI 剧默认 `volume: 0.10` |
| 任意路线，用户明确要代码合成氛围 | `music.style` | 只适合氛围衬底；AI 剧 lint 会警告，不作为默认 |

- **严禁**把内置 BGM 当 AI 剧的默认或模板残留。AI 剧写 `track=default` 会被 `bgm.resolve()` 拒绝；只有用户在对话里明确要求，才写 `{"track":"default","allowBuiltinTrack":true}`。
- **代码合成配乐（`score.py`）没有真正的旋律线**，用户实测评价“诡异、不轻松愉快”。它可以做氛围衬底、转场或临时小样，**不要用作 AI 剧的主配乐**。
- 新项目 `new_project.py --route ai-comic-drama` 的 `music` 是空对象；`lint.py` 会报 `AI 剧尚未选定配乐`，`audio.py` 会拒绝出片，直到你写入 `music.file`。

## AI 剧配乐标准流程

1. **按题材写 2 个候选提示词**（从下面的模板库选，或按同样结构自己写）。两个候选要在“情绪/乐器/节奏”上真正不同，不要只换一个词。
2. **告知费用**：`lingjing model list -t audio-synthesis` 里选 `MiniMax Music 2.6`。`lingjing model quote -t audio-synthesis "MiniMax Music 2.6"` 返回 `quote:null`（系统不报价）；本次实测每首约 **0.45 元**、约 1 分 50 秒、mp3、生成约 1 分钟。**以实际账单为准**，提交前让用户确认“2 首，预计约 0.9 元，系统不报价”。
3. **提交生成**（用户确认后才加 `-y`）：
   ```bash
   lingjing model exec -t audio-synthesis "MiniMax Music 2.6" \
     --set prompt="<提示词>" \
     --set lyrics="[Intro]
[Instrumental]" -y
   ```
   `lyrics` 用 `[Intro]` + `[Instrumental]` 表示纯音乐；不要把歌词写进去。
4. **下载到项目**：把返回的 mp3 放进 `assets/music/<题材>-候选1.mp3` 等相对路径，**不要**把临时 URL 写进工程。
5. **客观粗筛**（先淘汰明显不对的，不要直接给用户听一堆）：
   ```bash
   python scripts/music_screen.py assets/music/workplace-1.mp3 \
     --expect-mode major --bpm-min 100 --bpm-max 135 --centroid-min 1200
   ```
   看 `mode`、`bpm`、`spectralCentroidHz`、`brightness`；不通过的候选先淘汰。脚本只是粗筛，不能判断旋律好不好、是否贴合剧情。
6. **用户试听**：把通过粗筛的 1–2 个文件路径发给用户，明确说“请听这两首，选一首；没选之前不出片”。用户选中后写：
   ```json
   "music": {"file": "assets/music/workplace-final.mp3", "volume": 0.10}
   ```
7. **再合成**：`voice.py → timeline.py → audio.py → render.py --final → finalize.py`；交付说明写清“音乐由 MiniMax Music 生成、用户已试听确认”。

## AI 剧提示词模板库

每条都要求“纯音乐、无人声、无歌词”，并在提示词里写清**要什么**和**不要什么**。调式/BPM 是给生成器和粗筛的锚点，生成结果仍以试听为准。

### 1. 轻松职场 / 教学漫剧（本次成功案例，原样收录）

适用：职场培训、教学漫剧、知识型剧情；调式/速度：G 大调、120 BPM；乐器：木琴、尤克里里、轻快钢琴、拍手、口哨；旁白避让：音乐床压低，说话时自动闪避，高潮只放在无旁白或短句处。

```text
纯音乐，无人声，无歌词。非常欢快、阳光、开心的大调配乐，G大调，120 BPM，类似儿童动画或日系治愈番的欢乐背景音乐。主奏是明亮的木琴、尤克里里和轻快的钢琴，配拍手声和轻快的口哨，旋律上扬、跳跃、像蹦蹦跳跳的好心情，全程大调，全程明亮，没有任何阴郁、悬疑、紧张、忧伤或电子感，不要小调，不要低沉的音色。
```

### 2. 治愈日常

适用：生活流、治愈日常、温柔旁白；调式/速度：C 大调、82 BPM；乐器：钢琴、木吉他泛音、柔和弦乐、轻铃；不要：电子鼓、重低音、小调、紧张感；避让：对白段只留钢琴/弦乐长音，旁白密时不要加打击。

```text
纯音乐，无人声，无歌词。温柔治愈的日常配乐，C大调，82 BPM。钢琴为主，加入木吉他泛音、柔和弦乐和很轻的铃声，旋律简单、呼吸感强、留白多，像清晨阳光和安静的日常。全程大调，温暖、放松、不抢人声。不要电子鼓，不要重低音，不要小调，不要悬疑、紧张、忧伤或强烈节奏。
```

### 3. 搞笑喜剧

适用：搞笑短剧、段子、轻松二创；调式/速度：G 大调、120 BPM；乐器：拨弦、木琴、拍手、口哨、轻鼓；不要：阴郁、重低音、恐怖感；避让：笑点处留给音效，配乐在说话时降到背景。

```text
纯音乐，无人声，无歌词。俏皮、滑稽、轻松的喜剧配乐，G大调，120 BPM。用跳跃的拨弦、木琴、轻拍手、口哨和简单的轻鼓，节奏有弹性，像卡通片里人物蹦蹦跳跳、突然发现小惊喜。全程大调、明亮、可爱，不要阴郁，不要重低音，不要恐怖或悬疑感；段落之间留出给笑点和音效的空间。
```

### 4. 热血 / 成长 / 比赛

适用：成长、逆袭、比赛、团队冲刺；调式/速度：D 小调、128 BPM；乐器：鼓、弦乐、铜管、脉冲低音；不要：慵懒、爵士、过度电子；避让：高潮放在画面最强处，旁白密集时降为 build。

```text
纯音乐，无人声，无歌词。热血、向上、充满推进感的配乐，D小调，128 BPM。稳定的四拍鼓、紧凑的弦乐、短促铜管和脉冲低音，逐步加速、层层叠加，像比赛最后冲刺和团队一起向前。要有力量和希望，但不要喊叫、不要人声、不要慵懒爵士、不要过度电子；给旁白留出频段，不要在每句话上堆满鼓点。
```

### 5. 悬疑 / 惊悚

适用：悬疑、揭秘、危机、反转；调式/速度：E 小调、90 BPM；乐器：低频心跳、冷色合成器、稀疏弦乐；不要：明亮大调、欢快旋律、卡通感；避让：用低频和留白制造压力，对白段不要加高频刺音。

```text
纯音乐，无人声，无歌词。悬疑、克制的惊悚配乐，E小调，90 BPM。低频心跳般的脉冲、冷色合成器、稀疏弦乐和不协和的长音，留白多、慢慢积累压力，像发现线索但还没真相大白。不要明亮的大调旋律，不要欢快节奏，不要卡通感，不要人声；对白出现时只保留低频和空气感。
```

### 6. 古风 / 国风

适用：古风剧情、传统文化、历史人物；调式/速度：D 宫五声、92 BPM；乐器：古筝、笛子、琵琶、轻鼓、弦乐；不要：电子鼓、西式爵士、强烈合成器；避让：旁白段只用古筝/笛子单线条。

```text
纯音乐，无人声，无歌词。温润、清雅的古风配乐，D宫五声，92 BPM。古筝、笛子、琵琶为主，加入轻鼓和弦乐铺底，旋律有东方韵味、起伏自然，像山水和旧时光。不要电子鼓，不要西式爵士，不要强烈合成器，不要人声；旁白出现时只留古筝或笛子的单线条。
```

### 7. 科幻 / 科技

适用：AI、科技、未来、数据；调式/速度：A 小调、100 BPM；乐器：合成器脉冲、玻璃质感、轻电子鼓；不要：民乐、爵士、厚重管弦；避让：对白段降低高频脉冲，保留低频铺底。

```text
纯音乐，无人声，无歌词。干净、未来感的科技配乐，A小调，100 BPM。合成器脉冲、玻璃质感的音色、轻电子鼓和空气感铺底，节奏稳定、层次清楚，像数据中心和未来城市。不要民乐，不要爵士，不要厚重管弦，不要人声；旁白出现时降低高频脉冲，只保留低频和氛围。
```

### 8. 真人情感短剧

适用：真人情感、人物故事、温柔叙事；调式/速度：F 大调、80 BPM；乐器：钢琴、弦乐、木吉他、极轻鼓；不要：电子感、过重低音、悲伤小调；避让：对白为主，音乐只在句间和情绪转折处抬起。

```text
纯音乐，无人声，无歌词。温柔、克制的真人情感短剧配乐，F大调，80 BPM。钢琴为主，加入弦乐、木吉他和极轻的鼓，旋律简单、真诚、有呼吸感，像人物之间安静但重要的对话。全程大调，不要电子感，不要过重低音，不要悲伤小调，不要人声；对白为主，音乐只在句间和情绪转折处轻轻抬起。
```

## 客观粗筛

```bash
python scripts/music_screen.py <音频> --expect-mode major --bpm-min 100 --bpm-max 135 --centroid-min 1200
```

输出：`duration`、`bpm`、`key`、`mode`、`keyConfidence`、`spectralCentroidHz`、`brightness`、`checks`、`pass`。

- 调式用 chroma + Krumhansl 模板粗估；BPM 用 `librosa.beat.beat_track`；亮度用频谱重心。
- 本次成功提示词的目标：大调、约 120 BPM、明亮；第一次偏忧郁的 E 小调候选应在给用户听之前被淘汰。
- **本次实测参考**：最终选中的 MiniMax 曲粗筛为 D major / 123 BPM / 频谱重心约 1907 Hz / bright；第一次偏忧郁的 E 小调候选应在给用户试听前淘汰。
- **粗筛不能代替试听**：它判断不了旋律、编曲、是否贴合剧情、旁白是否被盖住；最终必须让用户听。

## 混音：AI 剧 `music.file` 默认 0.10

- AI 剧 `music.file` 默认 `"volume": 0.10`。本次最终混音：说话时配乐比人声低约 18–19 dB，无旁白时配乐约 -35 dB，用户认为可接受。
- `audio.py` 把旁白和生成视频自带的对白/环境音（`clipAudio`）一起送进闪避侧链：AI 剧默认闪避比 8:1，音乐床整体压低；代码动画保持原来的 0.62 / 6:1。
- 说话时音乐太吵：先把 `music.volume` 从 0.10 降到 0.08；仍吵就把该镜 `mood` 从 `climax` 降到 `build`。不要靠把人声整体拉爆来压音乐。
- 生成视频的 `clipAudio` 是独立输入，不会被音乐替换；对白和旁白都在侧链里，配乐会自动让路。需要保留环境音时不要把 `clipGain` 调得过低。
- `audio.py` 现在写 `audio/mix_report.json`：`source`、`musicFile`、`musicVolume`、`bedBusVolume`、`duckRatio`、`narrationScenes`、`clipAudioScenes`。交付前看一眼，确认音乐不是 `track:default`。

## 代码合成配乐（只做氛围衬底）

`music.style` 仍可用，风格有 `warm` / `bright` / `tech` / `cinematic` / `ambient` / `suspense` / `workplace` / `healing` / `comedy` / `hotblood`。它按分镜换和弦、加减鼓点，**但没有真正旋律线**，只适合：

- 代码动画的临时小样或氛围铺底；
- 转场、段落之间的空气感；
- 用户明确接受“合成器氛围”的场合。

AI 剧写 `music.style` 时 `lint.py` 会警告“只适合氛围衬底”；不要把它当主配乐。`score.py --list` 可以试听；`scripts/score.py --style workplace --seconds 20 -o test.wav` 只用于比较，不要作为最终 AI 剧配乐。

## 内置 BGM

`assets/music/vibe-knowledge.mp3`（《Vibe知识大赏》）只用于代码动画。文件、授权说明和分发范围都没有改。对外商用/投放前仍要让用户确认授权；不确定就改用有授权的 `music.file`。

## 替代方案（合成器/生成音乐都不合适时）

1. 用户自带的授权音乐：`{"file":"assets/music.mp3","volume":0.10}`；确认授权覆盖成片用途。
2. 其他授权的 AI 作曲服务：先说明用途、时长、风格和预算，**付费前报价并得到用户确认**；下载后放进 `assets/` 并登记。
3. 不要用来路不明或无商用授权的音乐；不要把“试听小样”说成最终成品。

## 质检

- `audio.py` 输出 `audio/score_report.json`（合成配乐）或 `mix_report.json`（混音参数）；`qa.py` 查削波、黑帧、冻结和联系表。
- 冻结阈值是 **6 秒**；`summary` / `endcard` 模板内置渐变角度、进度条、呼吸光等持续微动效，长停留页不要做成完全静态。
- 交付前请用户实际听：配乐好不好听、是否盖住人声、片尾是否收束，自动检查都替代不了。
