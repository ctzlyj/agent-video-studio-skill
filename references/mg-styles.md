# MG 风格卡与评审：15 种动效风格的做法、质感纹理、独立评审

这是一份做法与素材说明，不是规则。风格卡来自开源仓库 mg-styles-15（MIT，作者 Vincentwei1021，15 种风格各做了一支 10 秒成片并公开提示词和源码）。这里只取"这种风格靠什么被一眼认出来、怎么做"，换成本引擎的写法；不含它的故事、镜头和文案。哪种风格适合哪个项目、要不要用，由你判断，也可以自己设计新风格。

用法：用户点名某种风格，或你为方向（见 `style-design.md`）需要一个成熟参照时，读对应的卡，把"可检验特征"写进该项目的 `STYLE.md`，并在小样里逐条核对。

## 一、15 种风格卡

每张卡：**认出它靠什么** / **怎么做（数值是来源仓库提示词里的经验值）** / **在本引擎里怎么落地** / **配乐可选**。配乐名是 `scripts/score.py` 或 `music.style` 能直接用的最接近风格（本包的合成配乐只有 warm / bright / tech / cinematic / ambient / suspense 六种，见 `music.md`）。

| 风格 | 认出它靠什么 | 怎么做 | 在本引擎里怎么落地 | 配乐 |
|---|---|---|---|---|
| **扁平矢量** | 纯色大色块、几何化角色、5–6 色高饱和、无渐变 | 弹性过冲 `cubic-bezier(0.34,1.56,0.64,1)`，预备→冲出→回弹三段；错峰入场 2–4 帧；同一时刻只让一个主体动；位移带约 10% 挤压拉伸；转场用色块擦除或"物体飞出带走镜头" | `AVS.E.back` / `E.spring`，`enter(..., {ease:'back'})`；元素用 SVG 或 div | bright |
| **线条动画** | 单色等宽细线（2–4px），线自己画出来、连成一笔 | SVG `stroke-dasharray/dashoffset`（`getTotalLength`）；转角处略减速，`cubic-bezier(0.65,0,0.35,1)`；上一图形的尾线是下一图形的起线；线转面用同路径 fill 扩展；圆头端点 | `seg(lt,a,b)` 驱动 `dashoffset`；路径提前连好 | ambient / warm |
| **等轴 2.5D** | 30° 等角、无灭点、微缩场景、楼房"长"出来 | 正交相机（仰角 35.264°，方位 45°）；或 SVG 三个面做 SSR 变换（纵向缩 86.6%、斜切 ±30°）；Z 序 = 屏幕 y；楼房：底面先落位、立面 `scaleY` 0→1 带过冲、顶面晚 2–3 帧；运镜只平移不旋转，前中后景视差 1 : 0.8 : 0.6 | Three.js 层（`three-layer.js`）用 `OrthographicCamera`；或 DOM 层叠 | tech / bright |
| **3D 渲染质感** | PBR 材质（软胶、玻璃、金属）、浅景深、棚拍布光、克隆阵列 | 次表面 + AO + HDRI 三点布光；位移"前 20% 走完 80% 路程、收尾极慢"；24fps、浅景深；产品居中，粒子/布料围绕 | Three.js 层（已随包，1080p 约 0.14–0.25 秒/帧）；真 3D 动画需要 Blender（自取/重，本包不测） | cinematic / ambient |
| **逐帧手绘 / 线条沸腾** | 线条每隔几帧轻微抖动像在呼吸；纸纹底；烟火水花手绘点缀 | 24fps 下"一拍二"（实际 12fps）为主，快动作"一拍一"，静止"一拍三"；真 boil = 画 3–4 张微差线稿循环；smear 帧：快速位移的中间帧拉长 150%–300% 只留 1 帧；整体叠纸纹 multiply 10–15% | `AVS.hold(t, 12)` 把时间量化成"一拍二"；`texture.js`：`TEX.paper` + `TEX.grain(rate:12)`（颗粒每拍换位，就是 boil 的底）+ `TEX.dust` | warm / bright |
| **拼贴剪贴** | 照片剪影加白边、半调网点、报纸/牛皮纸纹、比例失衡的拼装 | 抠图后加 2–4px 白描边 + 半调滤镜；关节动画（锚点在肩/肘/颌，分段旋转，嘴巴用 2–3 张替换帧）；刻意降到 12 甚至 6fps，位置 ±2px 随机抖动；图层：纸纹→大色块→剪影→涂鸦/胶带→颗粒；转场用"手拍上来"或翻纸 | 抠图用 `rembg`（自取）；`TEX.paper` + `TEX.tape`（和纸胶带）+ `TEX.dust`；`AVS.hold(t, 12)` | warm |
| **液态流动** | 波浪边缘转场、拉丝与滴落、metaball 融合、永远没有直线 | 波浪前沿扫过画面，前沿 3–5 个错相位凸起；metaball = 高斯模糊 20px+ 再阈值（SVG `feColorMatrix` alpha 阈值）；拉丝—断裂—回弹；`cubic-bezier(0.22,1,0.36,1)` 前快后慢；次级液滴晚 2–3 帧跟随 | Canvas 或 WebGL 着色器（SDF + smooth-min）；已随包的着色器后期可叠辉光 | bright / ambient |
| **形变动画** | 轮廓连续过渡无跳变，形变带位移旋转与挤压拉伸 | 两形状顶点数一致、首顶点对齐，否则会打结；复杂 A→B 先收成中介简形（圆/胶囊）再展开，各 8–12 帧；叠 10–15% 挤压拉伸与轻微旋转；`cubic-bezier(0.7,0,0.3,1)`，起止各留 3 帧缓冲 | SVG path 插值（自取 flubber / polymorph）；抽查每个形变的中点静帧 | tech |
| **包豪斯 / 几何构成** | 基础几何、红黄蓝黑、严格网格、旋转绕几何中心 | 一切位移 = 网格模数的整数倍；缓动克制（easeInOutQuad 或匀速），不用过冲；一拍一个动作；旋转轴心三种交替（自身中心、边顶点、画面中心） | `E.inOut`；位置用 `FMT.w/FMT.h` 的整除网格；`music.bpm` 与动作节奏对齐 | tech |
| **复古 / Synthwave / Y2K** | 霓虹辉光、透视网格地平线、扫描线与 RGB 色偏、镀铬字 | 三件套：透视网格滚动 + 日落多层渐变球 + 双层辉光（内层紧 4px、外层散 30px）；VHS 链：RGB split 1–2px → 扫描线 → 波浪抖动（每秒 1–2 次 glitch）→ 4:3 圆角；Y2K 镀铬字 = 多段金属渐变 + 斜面高光 | `assets/fx/fx.js` 已含色差、辉光、故障、颗粒；网格/日落用 Canvas | cinematic / suspense |
| **弥散渐变 / 玻璃拟态** | 大色斑漂移、磨砂玻璃卡片、1px 高光描边、邻近色低对比 | 3–5 个大圆 blur 80–150px 沿贝塞尔路径 20–40 秒漂移；玻璃卡 = `backdrop-filter: blur(20–40px)` + 5–10% 白填充 + 1px 30% 白内描边 + 大圆角；邻近色 2–3 色，暗底亮斑；叠 3–5% 噪点防 banding；缓动接近线性，一切都慢，文字入场只用 opacity + 8px 位移 | CSS `backdrop-filter`（DOM 层）；`TEX.grain(op:.04)` 做防 banding 噪点 | ambient |
| **综艺花字** | 多层描边圆体胖体字、高饱和撞色 + 白边 + 投影、弹性 pop、配打击音效 | 三层结构：填充 + 粗白描边 + 彩色外描边/投影（`text-shadow` 多层或 SVG stroke）；入场 scale 0→1.15→1.0 约 8 帧，或逐字错帧 2 帧；情绪匹配（吐槽用歪斜字、惊讶用放射线爆炸框、尴尬用汗滴）；出现时机比语音晚 2–3 帧更自然；驻留时加轻微 wiggle | 竖屏 1080×1920；`transcribe.py --words` 对位关键词；`sfx` 的 pop / boing 类 | bright |
| **粗描边贴纸人科普** | 照片抠图加粗白描边变"贴纸"，冷灰蓝底，数据图表，大画布平移缩放 | 抠图 + 8–12px 白描边统一质感；超宽大画布（如 6000×3000）上做相机平移缩放（长缓动），一镜串多个信息点；图表：柱生长、数字滚动、路径描边；解说逐句驱动元素入场；2–3 色克制 | `rembg` 抠图；`assets/fx/world.js` 的一镜到底相机；`count()` 做数字滚动 | tech |
| **像素风** | 大颗粒像素、有限色板、低帧率精灵 | 内部分辨率低（如 320×180）再整数倍放大，最近邻插值（`image-rendering: pixelated`）；动画用阶梯时序（`steps()`），不用平滑缓动；精灵 6–8 帧循环 ~10–12fps；视差卷轴按整像素平移；可选 CRT 后处理（扫描线 + 桶形畸变 + 辉光），不要把像素糊掉 | Canvas 低分辨率画布放大；`AVS.hold(t, 10)`；`chiptune` 类配乐用 `music.style: bright` 近似 | bright |
| **赛博 HUD / FUI** | 青橙霓虹线框、目标锁定框、雷达扫描、等宽小字数据流 | 线框生长 = `stroke-dashoffset`，元素按层级错帧展开；环形雷达 = `conic-gradient` 旋转；数字滚动：随机数跳 3–5 帧后落定真实值；锁定框四角从大到小收缩（scale 1.4→1.0，快出缓入）；全局外发光 + 轻微色差 + 扫描线 | SVG/Canvas 层 + `fx.js`；数据用 `AVS.rand(seed)`，不要用 `Math.random` | suspense / tech |

跨风格的共同点（来源仓库的提示词反复出现）：一个风格只让一个主角在动；转场由元素带出而不是叠化；一个可检验特征写成数（缓动曲线、帧数、像素、色值），不写"要有弹性"这类形容。

## 二、质感纹理包

`assets/textures/`（随包约 5.6 MB，来源与授权见该目录的 `CREDITS.md`）。`new_project.py <项目> --textures` 拷进项目；`assets/fx/texture.js` 提供：

- `TEX.paper(root, {tone, k})` 纸张底（暖白纸 + 纤维）
- `TEX.grain(root, {kind:'fine'|'film35', op, rate})` 灰度颗粒，`rate` 次/秒换位（"一拍二"= 12），这就是 boil 的底
- `TEX.dust(root, {op, rate})` 尘点、划痕、纤维（4 张透明板轮换）
- `TEX.tape(root, {x, y, w, rot, kind:12|14, tint})` 和纸胶带
- `TEX.step(t)` 每帧在镜头的 render 里调一次

位置取整到固定拍点，同一 `t` 两次渲染逐像素一致（有测试）。叠加量按风格定：手作纸感 10–15%（来源仓库经验值）、玻璃拟态防 banding 3–5%。

## 三、运动模糊与"一拍二"

- `render.py --mb 4 --shutter 0.5`：每帧渲 4 个子时刻取平均，快速位移才有真实的拖影；快动作 `--mb 6 --shutter 1.0`。只对 CSS/Canvas 的位移有效（子时刻由 `render(t)` 的连续性决定）；代价是渲染时间乘以 `mb`。默认关闭，预览默认也关。可写进 `project.json`：`"render": {"motionBlur": {"samples": 4, "shutter": 0.5}, "workers": 3}`。
- `AVS.hold(t, 12)`：把时间量化到每秒 12 步，做"一拍二"、定格、像素风阶梯；24–30fps 输出里每拍保持两三帧。运动模糊与它一般不同时用（阶梯运动没有拖影）。
- `render.py --workers N`：N 个浏览器分段并行。**实测**（Windows，14 核，1080p、400 个带模糊和阴影的元素、180 帧）：1 个浏览器 36 秒，4 个 26 秒，约 1.4 倍；简单画面更慢（启动浏览器的开销大于收益）。像素与单浏览器相比平均差 0.1–0.9/255（编码分段处的 GOP 不同），单浏览器两次完全一致；三个独立浏览器渲同一时刻逐字节一致。所以：慢画面（着色器、3D）才值得开；要逐字节复现就用 1。

## 四、颜色：BT.709 标记

Chrome 出的是 sRGB。旧版编码没做 709 矩阵转换也没打标，播放器按 601 猜，饱和色会偏（实测 mint `#2EE6A8` 偏 23/255，红偏 13）。现在渲染命令加了 `scale=out_color_matrix=bt709` 和 bt709 标记，品牌色按 709 播放器解码后误差 ≤ 6（有测试）。已交付的旧片不受影响；重渲才会变。

## 五、独立评审

来源仓库的做法：成片出来后，**另开一个没见过代码的 AI**，只给它成片、规格和风格要求，让它打分并给改进清单；原制作会话按清单改一轮；两轮后再定稿（其 15 支片的评委终评在 7.57–8.21 分，满分 10）。评委默认偏宽：基准 5 = 合格学生作品、6 = 模板水平、7 = 扎实专业、8 = 高端广告公司、9 = 入围奖项、10 = 世界最佳；"大多数初版应得 5–7，不要放水"。

做法（本 skill 的落地）：

1. `python scripts/review_pack.py <项目>`：在 `qa/review/` 生成 0.5 秒一帧的联系表、围绕快动作/高潮的逐帧条带、全分辨率关键帧、实测规格（`spec.json`：时长、尺寸、帧率、响度、真峰值、黑场/冻结）。`--moves 3.2,7.5` 指定要看的时刻。
2. 把这些图和 `spec.json`、`STYLE.md`（或所选风格卡的"认出它靠什么"）交给另一个会话评审。
3. 评委的提示词（原文要点，可直接用）：

```text
你是一支动效短片的独立评委，没见过它的代码。材料：联系表、快动作条带、全分辨率帧、spec.json、风格要求。
1. 先看材料：联系表每 0.5 秒一帧；快动作与高潮的条带；全分辨率帧里看细节（边缘、排版、锯齿、色带、纹理、被裁切）。
2. 核对规格：时长、分辨率、帧率、有声、响度（约 -14～-16 LUFS）、真峰值 ≤ -1 dBTP、无计划外黑场/静止、画面重音与声音起音对齐。
3. 逐项 1–10 分（5=合格学生作品，6=模板水平，7=扎实专业，8=高端广告，9=入围奖项，10=世界最佳；大多数初版 5–7，不要放水）：
   风格还原（一眼能认出、每个标志特征都在）/ 创意冲击（前 0.5 秒钩子、一个明确高潮、收尾画面）/ 运动品质（缓动、间距、预备与跟随、弧线、无死帧无抖动）/ 版式排版（构图、层级、网格、含中文标点、色板、留白）/ 质感完成度（光、纹理、颗粒、无色带无锯齿）/ 声音与同步 / 技术（规格、字体加载、无故障）。
4. 给 5–10 条修改，按对最终观感的影响排序。每条写：时间码、可观察的问题、为什么重要、具体做法（缓动曲线、帧数、像素、色值）。多做几个大升级，少挑小毛病；至少一条要提高"惊艳度"，而不只是打磨。
5. 标为严重：像通用模板或 AI 套路、不自然的中文、回退字体或豆腐块、任何规格不达标。
输出：评分表、严重问题、修改清单。
```

4. 回到制作会话：先 `new_project.py --version` 保留当前版本，再逐条落实严重问题和高影响项；不要退步评委认为是优点的部分；重渲后再核对规格。

评审是自评的补充，不替代真实观看；评委看的是静帧，看不出节奏和声音，这两项仍要人听、人看。

## 六、没验到的（如实）

- 这 15 张卡没有逐一在本引擎里做出成片；落地列里的写法来自对来源源码的阅读和本引擎 API 的对照，只有运动模糊、并行渲染、"一拍二"取整、纹理叠加、BT.709 这几项做过实测。
- 来源仓库的配乐工具包（mgaudio：15 种配方、约 60 种音效、103 个乐器采样，48 kHz、-14 LUFS）没有并入。原因：它依赖 numba、pedalboard 等一批本包没有的库；采样索引登记了 598 个文件，仓库只带了其中 103 个（官方 README 也只说 103 个），所以用默认参数直接调配方时，会因为缺采样文件报错（实测 darksynth、glitch_hop、guofeng、lofi、synthwave、variety 报缺文件，acid、ambient、chiptune、explainer、future_bass、pop、techno、trap、vaporwave 能出 10 秒配乐）；来源仓库自己的 demo 配乐脚本能跑通（实测 05 和 10 两支出了 audio.wav），因为每支只调用自己用到的采样。本包的合成配乐（`score.py`，六种风格）和内置 BGM 保持不变。想要 mgaudio 那种强卡点配乐时，可以自取该仓库的 `lib/audio` 和对应 demo 的 `audio.py` 作参考。
- 来源仓库的字体、Blender 3D 片、完整的 15 支成片（420 MB）、展示网站没有并入。
