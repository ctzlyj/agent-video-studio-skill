# script-first：从想法或文章开始

方法参考 wtt-code-animation-studio（内容单一来源、配音后锁定时间轴）。该仓库无开源许可，只借鉴流程。

1. 先写剧本（旁白 + 每镜画面意图），给用户看；剧本确认前不选风格。
2. 推荐 1 个风格方向 + 2 个备选（按 `style-design.md`），用户选定。
3. 剧本落到 `project.json` 后先跑 `voice.py` 和 `timeline.py`，用真实配音时长锁定镜长，再写动画。
4. 验收分四层说清：结构检查通过（lint）→ 真实渲染通过（qa）→ 人工观感 → 用户采用。
5. 用户给的是文章、链接或现成口播稿时，先读 `references/article-intake.md`（抓取全文、版权提醒、事实对照、评论式脚本、一字不改的口播稿处理），再回到本流程第 1 步。
