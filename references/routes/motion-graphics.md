# motion-graphics：MG 动画 / 片头 / 品牌演绎

方法参考 mg-styles-15（钩子、节拍表、独立评审）与 bang-motion、motionmaxxing。15 种风格的特征与做法、纹理包、运动模糊、评审提示词见 `references/mg-styles.md`。

1. 片短（5–30 秒）就按"导演 + 动效设计 + 工程 + 声音"一人全包的标准做，目标是作品集水准，模板感即失败。
2. 0–0.5 秒必须有钩子；60–75% 处是高潮；结尾停 0.8–1.2 秒。
3. 写节拍表（cue sheet）：每个关键动作的时间点，画面动作和 `sfx` 都按这张表对齐；有音乐时动作落在拍点上（`music.bpm` 与动作节奏对齐，风格建议 `bright`，见 `references/music.md`）（拍点那一帧要有整屏可见变化）。
4. 运动品质：预备→挤压拉伸→过冲→回稳；一次一个主角在动；元素带出转场（物体飞出带走镜头）。
5. 出片后另开一个 Agent 按"风格还原、创意、运动、版式、质感、声画同步、技术"七项打分，按意见再修一轮：先 `python "$SKILL/scripts/review_pack.py" <项目> --moves <快动作与高潮时刻>` 生成证据包，评审提示词和打分基准见 `references/mg-styles.md` 第五节。
6. 点名了某种风格时，把该风格卡的"认出它靠什么"写成 `STYLE.md` 的可检验特征（写成数：缓动曲线、帧数、像素、色值），小样阶段逐条核对。
