# explainer：知识讲解 / 科普 / 教程

方法参考 huashu-art-motion（镜头表、文字镜头上限、交付门禁）与 iart-ai/explainer-video-skills。

1. 写镜头表：时间段、画面里的物、动作、镜头、屏上字、做法。开头 3 秒是一个具体小场景，全片用同一个具体例子贯穿。
2. 一个概念一个视觉隐喻，隐喻在全片保持一致（同一个角色、同一个容器、同一张图）。
3. 文字主导镜头 ≤30%；公式、流程、结构用逐步生长的图形表达。
4. 镜头运动有来有回：推近后要拉出或横移，不连续三镜往里推；过渡用缓，重音才快。
5. 严谨类内容（数理、医学、历史）每个事实进 `FACTS.md` 带出处；不确定的不讲。
