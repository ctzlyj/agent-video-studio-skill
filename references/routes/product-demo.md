# product-demo：真实软件/网页产品宣传片

方法参考 video-shotcraft 与 product-ui-promo：素材必须来自真实运行的产品。

1. 先做只读产品检查：能否打开、需要什么账号、哪些页面能展示（不展示敏感数据）。
2. 功能→镜头映射后，按定稿分镜采集素材：Playwright 截整页图、元素截图，并记录关键按钮/区域坐标（存 `assets/capture.json`）。
3. 镜头手法：在截图上做 2.5D 推镜到真实按钮、光标移动与点击涟漪、局部放大、前后状态切换。坐标来自采集记录，不要目测。
4. 需要真实操作过程时录屏（Playwright `record_video`），作为 `videos` 素材逐帧播放。
5. 账号、Cookie、个人信息、内部数据在采集时打码或换演示数据。
