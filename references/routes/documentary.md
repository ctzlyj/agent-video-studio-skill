# documentary：纪录片 / 发展史 / 大事记

GitHub 上没有可用的同名 archival-doc 包；本路线综合 lemo-opuscar 的 archive-lighttable、visual-investigation、newsreel 风格卡与 harness-documentario 的流程。

1. **事实先行**：先研究再写稿。每个年份、数字、人名、事件进 `FACTS.md`，注明来源链接或文档位置、原文措辞。只采用公开报道、官方发布或用户提供的内部资料；互相矛盾时写明并以官方为准。
2. **时间轴是骨架**：按阶段分章（3–6 章），每章一个转折事件 + 一个代表性数字。章节之间用统一的时间轴/年份转场。
3. **素材真实性**：历史照片、档案、Logo、截图用真实且有使用权的素材（用户提供、公有领域、CC0/CC BY 署名）。生图只用于氛围背景、质感和插画化场景，不得冒充历史照片或真实档案。
4. 镜头语法：年份大字落在物件上（档案卡、报纸、屏幕、地图），推近读一行原文，横移到下一件证据；结尾回到今天并给出展望。
5. 交付附 `FACTS.md`。
