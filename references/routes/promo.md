# promo：汇报片 / 产品介绍 / 项目宣传

目标是让决策者在 2–4 分钟内认可一件事。方法参考 xilo-opus-video（多方案先出样、brief 锁定）与 video-shotcraft（功能→镜头映射）。

1. 读用户材料，写 `FACTS.md`：结论一句话、3 个最硬的证据、真实数字及出处、产品/团队标准名称。
2. **功能→镜头映射表**：每个要讲的能力对应一个镜头和一个可视化手法（界面演示、前后对比、流程动画、数字滚动、架构分层、地图……）。不能可视化的能力合并或删掉。
3. 骨架：具体场景钩子 → 痛点 → 方案如何工作 → 能力演示（最多 5–6 个）→ 证据 → 价值 → 结尾（产品名 + 一句话；用户要求时加署名、Logo、联系方式）。
4. 真实界面优先：用户给截图/录屏就用真实素材做推镜、高亮和标注；没有就用代码画简化界面，不要用生图模型伪造产品界面。
5. 时长按用户要求；需要压缩时，演示段 `speed` 1.2–1.3，结论段 1.0–1.15。
6. 用户要署名时写进 `brand.credit`，放在字幕区之上；用户没提就不加。
